# Padel App — Экран «Турниры» (V2 Match-for-me)

Спецификация редизайна экрана списка турниров. Вкладка «Открытые» в табе «Турниры».

---

## Что изменилось vs. оригинал

| Было | Стало |
|---|---|
| Плоский список карточек без иерархии — всё одинаковое | Два чётко разделённых блока: **«Для вас»** (премиум-карточки под ваш уровень) и **«Остальные турниры»** (список сгруппирован по клубам) |
| Дата слева, название справа — глаз прыгает | Всё выровнено по одной вертикали: день+время слева, заголовок+подзаголовок в середине, статус справа |
| «16/16» и «Мест нет» дублировались | Одно явное состояние: зелёный chip для открытых (6/8), красный chip **ЗАПОЛНЕН** с иконкой-крестиком для полных |
| Формат турнира (Американо/Групповой) — маленькая серая пилюля | Цветной chip: синий для Американо, фиолетовый для Групповой — основной фильтр виден сразу |
| Группировка по клубу ADD Padel Almaty (и др.) давала только раздел, но не помогала понять где играть | Крупный логотип клуба + название + город + счётчик «открыто / всего» — невозможно записаться не туда |
| Уровень «2.0-3.75» без контекста | Level bar с точкой «Вы: 3.75» — визуально видно попадаешь в диапазон или нет |
| Заполненные и открытые визуально одинаковы | Заполненный турнир: opacity 0.55, зачёркивание названия пунктиром красным, диагональная штриховка, без CTA-кнопки |

## Структура экрана сверху вниз

1. **Header**: «Турниры» 26px/700
2. **Tab bar**: Открытые · Мои · Архив. Активный — зелёный underline 2px.
3. **Filter pills**: Все · Уровень · Формат · Дата · Клуб. Первый — активный (green-soft).
4. **Секция «Для вас»**
   - Title + chip «Уровень 3.75» + счётчик справа
   - Группировка по клубам: компактный sub-header (логотип 30px + название клуба 13px/700 + город 10px + число турниров зелёным)
   - Hero-карточки (см. ниже)
5. **Разделитель «Остальные турниры»**
   - Тонкая линия-gradient от прозрачного к rgba(255,255,255,0.08) и обратно
   - Лейбл 10px/700 caps по центру поверх линии
6. **Секция «Остальные турниры»**
   - Фон чуть темнее (`rgba(0,0,0,0.18)`) для визуального отделения
   - Группировка по клубам: большой sub-header (логотип 38px + название клуба 15px/700 + город 11px + «3/6 открыто»)
   - Компактный список строк внутри карточки клуба
7. **Bottom tab bar**: Главная · Турниры (active) · Бронирование · Рейтинг · Профиль

```
19 апр · 21:30 · Вс

Уровень 2.00        Вы: 3.75         3.75
━━━━━━━━━━━━━━━━━━━━━━━━●━━━

▓▓▓▓▓▓▓▓▓▓▓░░░  4 мест                            22к ₸
```

**Изменения для заполненного турнира (`status: 'full'`):**
- Градиент меняется на красно-коричневый
- Border: `rgba(240,85,77,0.18)`
- Добавляется chip `ЗАПОЛНЕН` (uppercase, red-soft)
- Название цветом `--text-muted`
- Диагональная штриховка поверх всей карточки (decorative)
- Кнопка «Записаться» **убрана** — вместо неё пусто (правая колонка пустая)
- Цена перенесена в строку рядом с клубом: `ADD Padel Almaty · Алматы · 22к ₸`
- Level bar opacity 0.6
- Progress-бар мест красный, текст «16/16 мест нет» красным
- Нижней строки с ценой больше нет (цена наверху рядом с клубом)

## Row «Остальные турниры»

**Макет:**
```
СБ            L2.25+ Суббота  •                       6/8
17:00         [Американо] L2.25–2.50 · 18 апр         18к ₸
```

**Для заполненного:**
```
ВС            ̶L̶2̶-̶L̶3̶ ̶M̶i̶x̶-̶ ̶С̶у̶б̶б̶о̶т̶а̶                       [✕ ЗАПОЛНЕН]
16:30         [Американо] L2.00–3.75 · 18 апр
```

**Детали:**
- Время + день недели слева (44px, opacity 0.5 если full)
- Название turnirа + зелёная точка если `inRange`
- Строка подзаголовка: chip формата + диапазон уровня + дата
- Справа: `X/Y` зелёным (или `amber` если осталось ≤2 мест) + цена ниже. Для full — только chip-Заполнен с x-иконкой.
- При full — strikethrough по названию (красный пунктир 1.5px), opacity 0.55, диагональная штриховка на фоне строки.

## Данные

```ts
type Tournament = {
  id: number;
  date: string;              // 'YYYY-MM-DD'
  dateLabel: string;         // '18 апр'
  dayOfWeek: string;         // 'Сб' / 'Вс' / 'Пн'
  time: string;              // '16:30'
  name: string;              // 'L2.25+ Суббота'
  format: string;            // 'Американо' | 'Групповой + Плей-офф' | 'Групповой'
  formatColor: 'blue' | 'purple' | 'orange';
  club: string;              // 'ADD Padel Almaty'
  clubCity: string;          // 'Алматы'
  clubLogo: string;          // 'almaty' | 'astana' (слаг для логотипа)
  players: number;
  playersMax: number;
  price: number;             // тенге
  levelMin: number;          // 2.0
  levelMax: number;          // 3.75
  status: 'open' | 'full';
};
```

**Сортировка:**
- «Для вас»: `isInLevelRange(t, user.level)`, open сначала, full после
- «Остальные»: `!isInLevelRange`, группировать по `clubLogo`, внутри клуба — open сначала, затем full, далее по `date` + `time`
- Клубы в списке «Остальные» сортировать так, чтобы клубы с открытыми турнирами были сверху

## Интеракции

- Tap на hero-карточку открытого турнира → detail screen
- Tap «Записаться» → модалка подтверждения/оплаты
- Tap на заполненный hero (или строку) → detail screen (можно посмотреть список игроков / добавиться в waitlist, если реализовано)
- Tap на «🏛 Клуб sub-header» → экран клуба с полным списком турниров
- Filter pills — открывают соответствующий фильтр/sheet
