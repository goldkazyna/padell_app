## Дизайн-токены (строго соблюдать — это тема приложения V3)

```
--bg:        #131317   /* фон экрана */
--card:      #1C1C21   /* карточки, чужие пузыри, поле ввода */
--card2:     #23232A   /* приподнятый слой, hover */
--accent:    #22C47A   /* зелёный — свои пузыри, активные состояния, бейджи */
--accent-soft: rgba(34,196,122,0.14)
--amber:     #EAB34E
--orange:    #F08446
--error:     #F0554D
--text:      #F3F3F5   /* основной текст */
--text-2:    #A2A2AB   /* приглушённый */
--text-dim:  #6A6A73   /* очень тусклый */
--border:    rgba(255,255,255,0.06)
```

Шрифт Inter (400/500/600/700). Скругления: карточки/пузыри 16–18px, кнопки 12–14px,
круглые кнопки навигации 40×40. Тон — спокойный, спортивный, минимализм, без
неоновых градиентов. Иконки — тонкие outline (Material-стиль), рисуй inline-SVG.

## Что за фича (контекст, чтобы дизайн был осмысленным)

Внутри турнира — чат. Организатор при создании турнира выбирает режим записи:
**только организатор** / **участники** / **все**. Кнопка чата с бейджем
непрочитанных стоит в шапке экрана турнира. Только текст (без вложений на 1 этапе).
После завершения турнира чат становится read-only.

## Сделай эти фреймы (каждый — отдельный телефон-фрейм с подписью)

### Фрейм 1 — «Шапка турнира: кнопка чата + бейдж»
Покажи только верх экрана деталей турнира: слева круглая 40×40 кнопка «назад»
(chevron-left), справа — две круглые 40×40 кнопки: **чат** (icon
`chat_bubble_outline`) и **поделиться** (icon `ios_share`). На кнопке чата —
бейдж непрочитанных: маленький кружок `--accent` с белой цифрой «3» в правом
верхнем углу. Ниже — заглушка названия/тегов турнира (можно кратко), чтобы был
контекст. Кнопки: фон `--card`, бордер `--border`.

### Фрейм 2 — «Чат: активный, режим Участники» (основной экран)
- Шапка: круглая кнопка «назад» + по центру название турнира «Вечерний Американо»
  + под ним мелкая подпись-режим «Участники» (`--text-2`, 12px).
- Лента сообщений (заполни правдоподобно, RU):
  - **Чужое** сообщение — слева: аватар-кружок (инициалы), над пузырём имя +
    маленький бейдж уровня (напр. «3.5»), пузырь `--card`, текст `--text`,
    время `--text-dim` мелко.
  - **Сообщение организатора** — тоже слева, но с бейджем **«Организатор»**
    (`--accent-soft` фон, `--accent` текст) рядом с именем, ник акцентным цветом.
  - **Своё** сообщение — справа: пузырь `--accent`, текст белый, без аватара,
    время под пузырём.
  - Сделай 5–7 реплик вперемешку (организатор + 2–3 игрока + свои).
- Внизу — поле ввода: капсула `--card`, плейсхолдер «Сообщение…», справа круглая
  кнопка отправки `--accent` со стрелкой-самолётиком.

### Фрейм 3 — «Чат: read-only (турнир завершён)»
Та же лента, но вместо поля ввода — серая плашка на всю ширину: замок-иконка +
текст «Чат завершён — только чтение» (`--text-2`, фон `--card`, приглушённо).

### Фрейм 4 — «Чат: режим Только организатор, я — участник»
Лента — только объявления организатора (доска объявлений). Вместо поля ввода —
плашка «Писать может только организатор» (замок + `--text-2`).

### Фрейм 5 — «Удаление сообщения (long-press)»
Экран чата с открытым снизу bottom-sheet меню над одним сообщением: пункты
«Удалить» (иконка корзины, текст `--error`) и «Отмена». Фон-затемнение поверх ленты.

### Фрейм 6 — «Админ: блок настроек чата при создании турнира»
Фрагмент формы создания турнира (тёмные карточки-строки, как в остальной админке):
- строка-тумблер «Чат турнира» (переключатель справа, вкл);
- ниже — сегмент-переключатель из 3 сегментов: **Только организатор** /
  **Участники** / **Все** (активный сегмент — `--accent` заливка / акцентный текст,
  выбран «Участники»);
- под ним — пояснение мелким `--text-2`: «Кто может писать в чат. Читать могут
  все, кому доступен чат.»

## Требования к качеству

- Пиксель-аккуратность: единые отступы (16px внешние поля), выравнивание пузырей,
  «хвостики» пузырей не нужны — просто скруглённые прямоугольники с асимметрией
  (у своих меньше скругление правого-нижнего угла, у чужих — левого-нижнего).
- Реалистичный контент на русском, живые имена и реплики про падел
  («Кто на 19:00?», «Корт 2 свободен» и т.п.).
- Всё в одном файле, открывается двойным кликом. Подписи под каждым фреймом —
  `--text-dim`, 13px.
- Не выдумывай другие цвета вне палитры выше. Не добавляй логотипы/бренды.

Верни только готовый HTML-файл.
