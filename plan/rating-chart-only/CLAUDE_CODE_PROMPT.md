# Карточка «Динамика рейтинга» — визуальная спецификация

Реализуй карточку строго по приложенному скриншоту. Данные/эндпойнты использовать из существующих в проекте — здесь только про **внешний вид** и **поведение элементов**.

Карточка располагается на экране Профиля **между hero-блоком (имя/рейтинг/уровень/статистика) и кнопкой «История турниров»**.

## Шапка (top row)

Слева:

1. Caps-label «ДИНАМИКА РЕЙТИНГА»
   - `font-size: 11px`
   - `font-weight: 700`
   - `letter-spacing: 1.2px`
   - `text-transform: uppercase`
   - `color: var(--dim)`

2. Под лейблом — две строки в одну линию (`display:flex; align-items:baseline; gap:8px; margin-top:4px`):
   - Большое число рейтинга на момент выбранной точки.
     Формат: `3 890` (с пробелом-разделителем тысяч).
     `font-size: 26px; font-weight: 800; letter-spacing: -0.5px; line-height: 1; color: var(--text)`.
   - Дельта рейтинга выбранного месяца.
     Положительная: `↗ +35`, цвет `var(--green)`.
     Отрицательная: `↘ -28`, цвет `var(--red)`.
     `font-size: 13px; font-weight: 800`.

Справа в шапке — ничего. Никакого `Место #N`, никаких period-pills.

## График (под шапкой)

- SVG, отступ от шапки `margin-top: 8px`.
- Высота примерно `96px`, ширина — на всю карточку.
- viewBox `0 0 320 96`, `preserveAspectRatio="none"`, `overflow: visible` (чтобы тень/glow точки не обрезались).
- Внутренние padding'ы: слева/справа 8px, сверху 18px, снизу 4px.
- Подписей месяцев под графиком **нет**. Никакой оси, никакой сетки, никаких лейблов осей.

### Кривая

- Catmull-Rom smoothing по точкам месяцев (12 точек).
- Stroke: `var(--green)`, `stroke-width: 2px`, `stroke-linejoin: round`, `stroke-linecap: round`.
- Под кривой — area-fill вертикальный градиент:
  - `0%`: `var(--green)` opacity `0.30`
  - `100%`: `var(--green)` opacity `0`

### Точки на кривой

- 12 круглых точек, по одной на каждый месяц.
- Каждая точка кликабельна. Расширенная hit-area `r=14px` (transparent circle поверх).
- Видимая точка:
  - **Неактивная**: `r=3px`, `fill: var(--green)`, `stroke: var(--card)`, `stroke-width: 2px`.
  - **Активная (выбранная)**: `r=4.5px`, `fill: var(--green)`, `stroke: var(--card)`, `stroke-width: 2.5px`.
    Под ней — мягкий glow: `circle r=9px, fill: var(--green), opacity: 0.18`.
- По умолчанию активна **последняя точка** (текущий месяц).
- При клике/тапе на любую точку — она становится активной, шапка пересчитывается: «3 890 ↗ +35» → значения рейтинга и дельты выбранного месяца.

### Vertical guide

От активной точки вниз до низа графика — пунктирная вертикальная линия:
- `stroke: rgba(34,196,122,0.3)`
- `stroke-dasharray: 2 3`

## Блок «Последние 15 матчей» (под графиком)

Отделён сверху:
- `margin-top: 14px`
- `padding-top: 14px`
- `border-top: 1px solid var(--border)`

### Под-шапка блока

Flex-row, `justify-content: space-between; align-items: center; margin-bottom: 8px`:

- Слева — caps-label `ПОСЛЕДНИЕ 15 МАТЧЕЙ`
  - `font-size: 11px; font-weight: 700; letter-spacing: 1.2px; text-transform: uppercase; color: var(--dim)`
- Справа — счётчик `11 П · 4 П` (победы · поражения)
  - `font-size: 11px; font-weight: 700; color: var(--muted)`

### Ячейки матчей

15 равных по ширине ячеек в одну строку (`display: flex; gap: 3px`).

Каждая ячейка:
- `flex: 1; height: 26px; border-radius: 4px`.
- Цвет:
  - Победа → `background: var(--green)`
  - Поражение → `background: var(--red)`
- **Прозрачность зависит от размера дельты рейтинга в этом матче**:
  - Победа: `opacity = 0.45 + min(delta, 30)/60`
  - Поражение: `opacity = 0.55 + min(|delta|, 30)/60`
  Чем больше абсолютная дельта — тем ярче (плотнее) ячейка. Это даёт визуальный «вес» каждого матча.
- Внутри — буква-метка: «П» (победа) или «П» (поражение)
  Можно заменить на «W»/«L» если такой стиль уже в продукте.
  - `font-size: 9px; font-weight: 800`
  - Цвет в победе: `#06281a` (тёмно-зелёный), в поражении: `#fff`.
  - Центрирование: `display: flex; align-items: center; justify-content: center`.

### Подписи под полосой

Flex-row, `margin-top: 6px; justify-content: space-between`:
- Слева: «15 матчей назад»
- Справа: «сейчас»
- Обе: `font-size: 9px; font-weight: 600; color: var(--dim)`.

## Состояния

- **Default**: активна последняя точка, шапка показывает текущий рейтинг и дельту последнего месяца.
- **Точка выбрана**: меняется только содержимое шапки (число + дельта) и визуал активной точки. Сам график не перерисовывается.
- **Hover на точке** (на desktop): cursor `pointer`, можно лёгкое осветление точки до `r=4px`.
- **Mobile**: тап по точке = выбор. Хит-area достаточная (14px радиус), чтобы попадать пальцем.

---

## Что не делать

- Не добавлять period-pills (1М/3М/6М/1Г/Всё) — в шапке их нет.
- Не показывать «Место #N» — этот блок убран.
- Не подписывать месяцы под точками графика.
- Не добавлять tooltip над точкой — все цифры выводятся в шапке.
- Не использовать сторонние chart-библиотеки. SVG inline, ~80 строк кода — этого достаточно.
