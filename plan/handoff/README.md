# Padel App — Настройки профиля (V3)

Спецификация для разработчика. Вариант **V3 Карточный** финального редизайна экрана «Настройки профиля».

---

## Что изменилось vs. оригинал

| Было | Стало |
|---|---|
| Большой аватар по центру без контекста | Hero-карточка: аватар + имя + город + уровень + бейджи + прогресс заполнения |
| Каждое поле в отдельной карточке | Поля сгруппированы в секции: **Контакты**, **О вас**, **Игровой стиль** |
| Одинаковые чипы разбросаны | Inline-строки с иконкой слева → глазами сразу видно о чём поле |
| Пустые поля «Не указан» без призыва | Amber-бейдж «Не заполнено» + подсказка зачем заполнять |
| Нет обратной связи о состоянии профиля | Прогресс-бар + % заполнения + подсказка какое поле добавить |
| «Сохранить» маленькой ссылкой сверху | Primary-кнопка полной ширины внизу + бейдж в шапке |

## Поведение (state)

```ts
type Profile = {
  name: string;            // Имя
  phone: string;           // read-only
  city: string;            // Город (picker)
  gender: 'Мужской' | 'Женский' | null;
  age: number | null;
  hand: 'Правша' | 'Левша' | null;
  position: 'Справа' | 'Слева' | 'Любая' | null;
  preferredTime: 'Утро' | 'День' | 'Вечер' | null;
};
```

**Completion %** = (заполненных полей / 8) * 100

**Incomplete indicator** (amber) показывается на незаполненном поле при условии, что профиль < 100%.

**Save button**:
- В шапке — компактный бейдж (всегда видно)
- Внизу страницы — полноширинный primary (visible когда есть изменения)

## Для Claude Code — промпт

> Перепиши экран «Настройки профиля» в моём мобильном приложении по прилагаемому макету (файл `profile-v3.jsx`).
>
> Используй design tokens из `README.md` (цвета, типографика, отступы).
> Структура логики не меняется — только UI:
> - Hero-карточка с аватаром, именем, бейджами и прогрессом заполнения
> - Поля сгруппированы в 3 секции с заголовками
> - Каждое поле — inline-строка с иконкой слева
> - Выбор варианта (пол, рука, позиция) — chips внутри карточки секции
> - Primary-кнопка «Сохранить» внизу страницы
>
> Существующие хуки для сохранения данных, валидации и навигации сохранить. Проверь что работают и тёмная тема, и ranges (chips могут быть single/multi).
