# План реализации: Поединок (Challenge Match)

## Обзор
Новый раздел приложения — неформальные матчи 2v2 вне турнира. Пользователи создают поединки, приглашают друзей или находят открытые матчи.

---

## Экраны (дизайн → HTML-мокапы)

### 1. Список поединков (главный экран раздела)
- Табы: "Открытые" / "Мои"
- Карточка поединка: дата, время, клуб, тип (рейтинговый/товарищеский), заполненность (3/4), уровень
- Кнопка "Создать поединок" (FAB или внизу)
- Пустое состояние: "Нет открытых поединков"

### 2. Создание поединка
- Поля: дата/время, клуб (опционально), тип, уровень
- Схема корта 2x2 (выбор своей позиции)
- На пустых позициях: "+" → ввод телефона или оставить открытым
- Кнопка "Создать"

### 3. Детали поединка
- Схема корта с игроками (аватары, имена, рейтинг)
- Статус: ожидание игроков / готов к игре / завершён
- Кнопка "Занять место" (для открытых позиций)
- Кнопка "Ввести счёт" (для создателя, когда все на месте)
- Результат и изменение рейтинга (после завершения)

### 4. Ввод счёта
- Сетка 1-3 (до 2 побед) или фиксированное кол-во
- Счёт для каждого сета
- Подтверждение результата

### 5. Приглашение (bottom sheet)
- Ввод номера телефона
- Поиск игрока
- Отправка приглашения

## Этапы реализации

### Этап 0: Дизайн (HTML-мокапы)
- [ ] HTML-файл со всеми экранами в стиле приложения
- [ ] Согласование дизайна
- **Файл:** `plan/design_poedinok.html`

### Этап 1: Backend (Laravel)
- [ ] Миграция: таблица `challenges` (creator_id, club_id, scheduled_at, type, level, status, score)
- [ ] Миграция: таблица `challenge_players` (challenge_id, user_id, position 1-4, status: invited/accepted/declined)
- [ ] Модели: Challenge, ChallengePlayer
- [ ] API эндпоинты:
  - `GET /mobile/challenges` — список открытых
  - `GET /mobile/challenges/my` — мои поединки
  - `POST /mobile/challenges` — создать
  - `GET /mobile/challenges/{id}` — детали
  - `POST /mobile/challenges/{id}/join` — занять место
  - `POST /mobile/challenges/{id}/invite` — пригласить по телефону
  - `POST /mobile/challenges/{id}/accept` — принять приглашение
  - `POST /mobile/challenges/{id}/decline` — отклонить
  - `POST /mobile/challenges/{id}/score` — ввести счёт
  - `POST /mobile/challenges/{id}/cancel` — отменить
- [ ] Уведомления (FCM): invite, accepted, declined, ready, result
