# Скоро — секция турниров на главном экране (V2 «Calendar week»)

Спецификация для разработчика. Заменяет текущий блок «Скоро» (горизонтальный скролл с одной большой карточкой) на компактный календарный паттерн.

**Кнопка «Последние новости приложения» (Telegram) — не трогать. Оставляем как есть.**

---

## Что меняем

### Сейчас
- В блоке «Скоро» одна высокая карточка турнира на весь экран (~370px высоты), хотя турниров много.
- Чтобы увидеть следующий турнир — горизонтальный скролл, не очевидно что они там есть.
- Заголовок «Скоро» отдельно, никакой связи с датами.

### Становится
- Полоса дней (горизонтальный скролл, по умолчанию ~7 видимых) — каждый день: «СБ / 09» + точки-маркеры по числу турниров в этот день.
- Активный день подсвечен зелёным; ниже — список турниров именно этого дня в компактных строках (38px иконка + время + название + цена/мест).
- Высота секции уменьшается ~в 2 раза, видно сразу 3–4 турнира, и понятно когда какой день «забит».

```css
--border:       rgba(255,255,255,0.08);
--text:         #f3f3f5;
--muted:        #a2a2ab;
--dim:          #6a6a73;

--green:        #22c47a;
--green-dark:   #1a9e62;
--green-soft:   rgba(34,196,122,0.14);
--green-border: rgba(34,196,122,0.32);

--danger:       #ef4444;
```

Шрифт: системный stack (`system-ui, sans-serif`). Веса: 600 (regular labels), 700 (sub-labels), 800 (titles, numbers).

## Структура

```
<section "Скоро">
  ├ header row:   «Скоро»  ← title 18px/800           «Календарь →»  ← link green 13px/700
  ├ DayStrip:     горизонтальный скролл, 14 дней вперёд от сегодня
  │   └ DayCell × 14
  └ DayList:      список турниров выбранного дня
      └ TournamentRow × N
```

---

## DayStrip

- Контейнер: `display:flex; gap:6px; overflow-x:auto; padding:0 16px; scrollbar-width:none`.
- DayCell: `min-width:48px; padding:10px 8px; border-radius:12px; flex-direction:column; gap:4px`.

DayCell состояния:

| Состояние | background | border | dow color | day color |
|---|---|---|---|---|
| Idle | `--card` | `1px solid --border` | `--dim` | `--text` |
| Selected | `--green-soft` | `1px solid --green-border` | `--green` | `--green` |

Внутри DayCell:
1. **DOW** (Пн/Вт/…) — `font-size:10px; font-weight:700; letter-spacing:0.6px; text-transform:uppercase`.
2. **Day** — `font-size:18px; font-weight:800; letter-spacing:-0.3px`.
3. **Dots row** — `height:5px; display:flex; gap:2px`. По одной точке на турнир в этот день, диаметр 4px, цвет `--green`. Если турниров нет — одна серая точка `rgba(255,255,255,0.08)` (плейсхолдер чтобы высота не прыгала).

Сегодняшний день показывает «Сегодня» вместо DOW (опционально), либо просто DOW — мы выбрали последнее, для единообразия.

## DayList (TournamentRow)

Контейнер: `padding:0 16px; display:flex; flex-direction:column; gap:8px`.

Строка `TournamentRow`:

```
[logo 38×38] [time + meta] [title] [price + filled]
```

- Контейнер: `background:--card; border:1px solid --border; border-radius:12px; padding:12px 14px; display:flex; align-items:center; gap:12px`.
- **Logo** — `width:38px; height:38px; border-radius:8px;` фон = бренд-цвет клуба (мы зашили: ADD Astana = #fbbf24, ADD Almaty = #22c47a, PadelHouse = #4f87ff). Внутри инициалы клуба, 11px/800, цвет `#000`.
- **Центр**:
  - top-line: `время` (11px/700, color `--green`) · точка-разделитель 3×3 цвет `--dim` · `формат · L уровень` (11px/600, color `--muted`).
  - title: 14px/800, letter-spacing −0.2px, color `--text`. `text-overflow:ellipsis; white-space:nowrap`.
- **Right**:
  - price — 13px/800, color `--text`.
  - sub: `N/M мест` 10px/700, color `--muted`. Если `filled/max ≥ 0.875` — color = `--danger`.

Тап по строке открывает экран турнира.

---

## Логика

- Сегодняшний день = первый элемент DayStrip.
- 14 дней вперёд (можно сделать 21–28, если позволяет API).
- При смене выбранного дня — заменяется содержимое DayList. Анимация: fade 150ms.
- Если в выбранном дне 0 турниров — показать empty-state (та же ракетка-иллюстрация что в «Активный турнир», текст «На этот день турниров нет», CTA «Все турниры →»).
- Если в DayStrip совсем нет турниров на ближайшие 14 дней — секция «Скоро» вообще скрывается, а на её месте остаётся ссылка «Все турниры в календаре →».

## Что отдать в API

`GET /tournaments/upcoming?days=14` → массив:

```json
[
  {
    "id": 123,
    "date": "2026-05-09",
    "time": "11:00",
    "title": "L2.5+ Суббота",
    "club": { "id": 1, "name": "ADD Padel Astana", "logoText": "ADD", "brandColor": "#fbbf24" },
    "format": "Американо",
    "level": { "min": 2.5, "max": 2.75 },
    "price": 18000,
    "currency": "₸",
    "filled": 7,
    "max": 8
  }
]
```

Группировка по `date` делается на клиенте.
