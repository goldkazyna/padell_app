## Что должен делать пользователь — пользовательский флоу

### Создание поединка
1. Пользователь открывает раздел "Поединок"
2. Нажимает "Создать поединок"
3. Выбирает параметры:
   - Дата и время
   - Место/клуб (опционально)
   - Тип: **Рейтинговый** (влияет на ELO) или **Товарищеский** (не влияет)
   - Уровень поединка (для открытых матчей)
4. Видит схему корта — 4 позиции (2 на каждой стороне)
5. Выбирает свою позицию
6. На остальные 3 позиции может:
   - Ввести номер телефона → игрок получит приглашение
   - Оставить пустым → место открыто, любой может занять

### Открытые поединки
- Пользователь видит список доступных поединков (фильтр по уровню)
- Может занять свободное место

### Проведение поединка
- Когда все 4 места заняты — создатель вводит счёт
- Если рейтинговый — ELO пересчитывается (использовать существующую логику)

### Приглашения
- Приглашённый игрок получает уведомление
- Может принять или отклонить

## Визуальный элемент — схема корта

Ключевой UI-элемент: схема корта 2x2, где пользователь тапает на позицию.

```
┌─────────────┬─────────────┐
│  позиция 1  │  позиция 3  │
│             │             │
│  позиция 2  │  позиция 4  │
└─────────────┴─────────────┘
     Сторона A     Сторона B
```

- Тап на позицию = выбрать её (своя позиция подсвечивается)
- На пустых позициях иконка "+" → ввод номера телефона или оставить открытым
- На занятых позициях — аватар/имя игрока
