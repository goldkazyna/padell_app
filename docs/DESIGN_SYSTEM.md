# Дизайн-система приложения

Свод правил вёрстки Padel KZ. Смысл документа простой: одинаковые по смыслу
элементы должны выглядеть одинаково на всех экранах. Если тебе нужен чекбокс,
кнопка «назад», таблица или карточка — бери готовое отсюда, не рисуй своё.

Новый общий элемент кладём в `lib/widgets/` и описываем здесь же.

**Перед тем как верстать новый экран:**

1. Найди в разделе «Каталог готового» то, что уже решает задачу.
2. Если решения нет — посмотри соседний экран того же смысла и повтори его.
3. Если делаешь новое общее — вынеси в `lib/widgets/` и допиши сюда.

## Токены

Цвета живут в `lib/theme/app_theme.dart`. Хардкод `Color(0xFF...)` в экранах —
только для оттенка, которого нет в теме и который нужен ровно в одном месте.

| Токен | Значение | Что им красим |
|---|---|---|
| `AppTheme.background` | `#0E1512` | фон экрана |
| `AppTheme.card` | `#1C2421` | карточка, лист, шторка |
| `AppTheme.cardRaised` | `#232D29` | карточка на карточке, поле ввода |
| `AppTheme.accent` | `#22C47A` | основное действие, «включено», своя строка |
| `AppTheme.accentSoft` | `#22C47A` 14% | фон бейджа и подсветка своей строки |
| `AppTheme.amber` | `#EAB34E` | заголовок таблицы лидеров, кубок |
| `AppTheme.orange` | `#F08446` | предупреждение, ожидание, «мест мало» |
| `AppTheme.error` / `errorSoft` | `#F0554D` | ошибка, удаление, «мест нет» |
| `AppTheme.blue` | `#4A8BF5` | формат турнира (тип) |
| `AppTheme.textPrimary` | `#F3F3F5` | название, значение |
| `AppTheme.textSecondary` | `#A2A2AB` | подпись, мета-строка |
| `AppTheme.textDim` | `#6A6A73` | третьестепенное: точки-разделители, «из 16» |
| `AppTheme.border` | белый 6% | рамка карточки на тёмном фоне |
| `AppTheme.divider` | белый 5% | разделитель строк списка |

Палитру не расширяем: `accent`, `orange`, насыщенный `#7C3AED` для отдельных
акцентов. Бледный `AppTheme.purple` не использовать. Новый цвет — только по
согласованию, иначе через месяц в приложении пять оттенков зелёного.

Токены **не `const`** (наследие светлой темы), поэтому
`const TextStyle(color: AppTheme.accent)` не скомпилируется — так и задумано.

### Шкала размеров

Отступы и скругления берём из короткого набора, а не «на глаз»:

- **отступы:** 4 · 6 · 8 · 10 · 12 · 14 · 16 · 20 · 24
- **скругления:** 6 (бейдж) · 10 (поле, кнопка-строка) · 12 (внутренний блок) ·
  14 (карточка, primary-кнопка) · 16 (крупная карточка, шторка сверху)
- **аватар:** 20 (в таблице) · 34–38 (строка списка) · 44 (шапка) · 64+ (профиль)

### Шкала шрифта

| Размер | Вес | Где |
|---|---|---|
| 19–22 | w800 | заголовок экрана внутри контента |
| 16–17 | w700 | название карточки, заголовок шторки |
| 14.5–15 | w600 | название строки списка |
| 13–14 | w400–600 | основной текст, значения |
| 12–12.5 | w400–600 | мета-строка под названием |
| 10–11 | w700–800 | бейджи, заголовки колонок, подписи-капсы |

Цифры, которые стоят в колонку (рейтинг, очки, счёт, цена), пишем с
`fontFeatures: [FontFeature.tabularFigures()]` — иначе строки «пляшут».

## Карточка

Базовая карточка — один и тот же рецепт на всех экранах:

```dart
Container(
  decoration: BoxDecoration(
    color: AppTheme.card,
    borderRadius: BorderRadius.circular(14),
    border: Border.all(color: const Color(0xFF2A3330), width: 0.5),
  ),
  padding: const EdgeInsets.all(14),
  child: ...,
)
```

- **радиус 14** для обычной карточки, **16** — для крупной (шапка экрана, блок
  во всю ширину), **12** — для блока внутри карточки;
- рамка `#2A3330` (или `AppTheme.border`), толщина 0.5;
- **своя карточка подсвечивается** акцентной рамкой
  `AppTheme.accent.withValues(alpha: 0.35)`, а не другим фоном;
- недоступная (мест нет, отменён) — рамка `AppTheme.error` 18% и текст
  приглушается, но карточка не исчезает.

Порядок содержимого сверху вниз всегда один: **дата/статус → название →
формат и цена → место → шкала**. Именно в таком виде собраны карточка
турнира и карточка лиги, и менять порядок в новых карточках нельзя — человек
читает их пачкой и ищет одно и то же на одном месте.

## Строка списка

Строка (участник, игрок рейтинга, этап лиги) — это `Row`:

```
[ 34–38 квадрат: аватар / номер / медаль ]  [ имя + мета ]  [ значение ]  [ действие ]
```

- слева — ровно один квадрат/круг фиксированного размера, чтобы список не
  «плыл»; внутри — аватар, номер места или медаль;
- имя — `textPrimary` 14.5 w600, одна строка с `ellipsis`;
- под именем — мета-строка `textSecondary` 12, элементы через ` · `;
- справа — число (рейтинг, очки) `tabularFigures`, затем действия;
- разделитель между строками — `AppTheme.divider` 0.5, а не отступ.

## Место и медаль

Единое правило для всех мест — своё, чужое, в истории, в лиге:

- **1–3 место — `Medal(place:)`**;
- **4 и дальше — число места** в том же квадрате, `textSecondary` w800;
- **места нет** (не играл, ещё не сыграно) — `Icons.emoji_events_outlined`
  приглушённым цветом.

Номер этапа, тура или группы в этот квадрат ставить нельзя: цифра рядом с
именем читается как место (проверено на лигах — «этап 2» приняли за 2 место).
Номер уходит в мета-строку словом: «этап 2 · 4 сент. · моё место 4».

## Таблицы турниров

Все таблицы очков — это `FlexStandingsTable` в карточке с заголовком:

```dart
Container(
  decoration: BoxDecoration(
    color: AppTheme.card,
    borderRadius: BorderRadius.circular(14),
    border: Border.all(color: const Color(0xFF2A3330)),
  ),
  child: Column(children: [
    // «🏆 Таблица лидеров»
    Padding(padding: const EdgeInsets.fromLTRB(14, 12, 14, 4), child: ...),
    Padding(
      padding: const EdgeInsets.fromLTRB(6, 0, 6, 6),
      child: FlexStandingsTable(
        leaderboard: rows,
        currentUserId: myId,
        nameMinWidth: 112,          // если ФИО жмутся
        extraColumn: ('Э', 'этапов сыграно', (r) => '${r['stages']}'),
      ),
    ),
  ]),
)
```

Правила таблиц:

- **горизонтальный скролл, а не сжатие**: колонки не ужимаются под экран,
  таблица едет вбок; легенда остаётся снаружи прокрутки;
- имя разбивается на две строки (`StandingsName`): имя сверху, фамилия снизу;
- заголовки колонок — одна буква, расшифровка в легенде (`StandingsLegend`);
- порядок колонок: `#`, аватар, игрок, [доп. колонка], **В, П, Н**, З, Пр, ±, М, Ср;
- проценты не показываем — игроки их путают с процентом побед;
- своя строка подсвечена `accentSoft`, поэтому `currentUserId` передаём всегда;
- галочка подтверждённого уровня рядом с именем — поле `verified` в строке.

## Кнопки

- **основное действие** — `AppPrimaryButton`: зелёная заливка, **чёрный** текст,
  радиус 14, высота 52 (`compact: true` — пилюля внутри карточки);
- **второстепенное** — прозрачная кнопка с рамкой `#2A3330` и текстом
  `textSecondary`;
- **опасное** (удалить, отменить) — текст/иконка `AppTheme.error` на прозрачном
  фоне; заливать красным целую кнопку нельзя, кроме подтверждения в диалоге;
- **иконка без подписи** — только если действие очевидно из контекста строки
  (крестик «убрать»); всё остальное подписываем словом.

Нижняя панель экрана с главным действием: карточка во всю ширину, фон
`AppTheme.card`, отступы 16, кнопка внутри — так сделаны детали турнира и лиги.

## Диалоги и шторки

- **вопрос «точно?»** — `AlertDialog` с `backgroundColor: AppTheme.card`,
  радиус 14, заголовок 16 w700, кнопки: «Отмена» (`textSecondary`) и действие
  (`AppTheme.error` для удаления);
- **выбор из списка, форма** — `showModalBottomSheet` с
  `backgroundColor: Colors.transparent` и контейнером `AppTheme.card`,
  скругление сверху 20, «ручка» 38×4 цветом `#2A3330`, отступы 20;
- шторка учитывает клавиатуру: `padding: EdgeInsets.only(bottom: viewInsets.bottom)`;
- **результат действия** — `showAppAlert`, никаких `SnackBar`.

## Пустые состояния

Пустой список — это карточка с текстом по центру, а не голая надпись:

```dart
Container(
  padding: const EdgeInsets.symmetric(vertical: 32, horizontal: 20),
  decoration: BoxDecoration(
    color: AppTheme.card,
    borderRadius: BorderRadius.circular(16),
    border: Border.all(color: const Color(0xFF2A3330), width: 0.5),
  ),
  child: Center(child: Text(text, textAlign: TextAlign.center, ...)),
)
```

Текст говорит, **что делать дальше**, а не только «пусто»: «Этапов ещё нет.
Добавьте первый — состав лиги запишется сам».

## Бейджи и статусы

- бейдж — капсы 10 w800, `letterSpacing` 0.5–0.6, радиус 4–6, фон = цвет
  статуса 12–16% (`accentSoft`, `orange.withAlpha(25)`, `errorSoft`);
- статус словом, а не цветом в одиночку: цвет дублирует смысл, а не заменяет;
- формат турнира пишем полным названием (`Американо`, `Americano Flex`) синим
  `#3B82F6`; в лиге — тем же цветом, потому что это тот же смысл.

## Прогресс и шкалы

Тонкая шкала 4px, радиус 2, фон `#0DFFFFFF`, заливка `AppTheme.accent`; рядом
подпись, что именно она показывает («этап 2 из 8», «15 из 16»). Оранжевая
заливка — когда осталось мало мест, красная — когда мест нет.

## Аватары и логотипы

- игрок — `PlayerAvatar` (фото → инициалы → инициалы при битой ссылке);
- клуб — `ClubLogoTile` (логотип → инициалы на цветном квадрате);
- аватар показываем **везде, где показываем имя**: рейтинг, поиск, состав,
  результаты. Человек с фото в рейтинге и безликий кружок в поиске выглядят
  как два разных приложения;
- сервер должен отдавать **готовую ссылку**: путь вида `/logos/x.png` виджет
  показать не сможет и нарисует инициалы (ловили на лигах).

## Иконки

Только монохромные `Icons.*`. Цветные эмодзи в интерфейсе не используем: они
по-разному выглядят на Android и iOS и ломают строгий вид тёмной темы.

## Тексты

Все пользовательские строки — через `AppLocalizations` (RU, EN, KK). Хардкод
запрещён; исключение — админские экраны клуба.

Подписи пишем от лица человека, а не системы: «Соберите пары и нажмите
„Сохранить пары“», а не «Ошибка валидации состава».

## Чекбоксы

**Только `AppCheckbox`. Свои чекбоксы рисовать нельзя.**

```dart
AppCheckbox(checked: selected)
```

- квадрат 24×24, скругление 6;
- снятый — прозрачный, рамка `#3A3A3A` толщиной 1.5;
- отмеченный — залит `AppTheme.accent`, внутри чёрная галочка;
- нажатие вешается на всю строку, а не на сам квадрат.

Никаких `Checkbox`, `Switch` вместо чекбокса и `Icons.check_circle` в списках
выбора. `Switch.adaptive` остаётся там, где настройка одна и включается сама
по себе, а не выбирается из списка.

## Сворачиваемые блоки

**`AppExpandableSection`.**

```dart
AppExpandableSection(
  title: l10n.notifyCitiesTitle,
  summary: _citiesSummary(context),   // «Все города», «Алматы, Астана»
  description: l10n.notifyCitiesDesc, // видно только раскрытым
  children: [for (final city in _cities) _buildCityRow(city)],
)
```

- шеврон справа, поворачивается вниз при раскрытии;
- **сводка обязательна**, если по ней понятно текущее состояние;
- содержимое не строится, пока блок свёрнут;
- по умолчанию свёрнут; `initiallyExpanded` — когда внутри одна-две строки.

## Кнопка «назад»

**`AppBackButton`** — круглая 34×34, одинаковая на всех вложенных экранах.

## Чего не делаем

- не рисуем свой чекбокс, свою медаль, свою таблицу очков и свой аватар;
- не заводим новый оттенок зелёного/серого, если в теме уже есть подходящий;
- не ставим номер (этапа, тура, группы) туда, где человек ждёт место;
- не сжимаем таблицу под ширину экрана — только скролл вбок;
- не показываем `SnackBar`;
- не оставляем `TODO`-заглушку с пустым экраном: пустое состояние — тоже вёрстка.
