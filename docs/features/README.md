# Документация фич (padel)

Папка для подробных md-справок по крупным фичам проекта — чтобы в будущем
можно было быстро вернуться и понять, что и где сделано, без чтения всего кода.

Проект состоит из двух репозиториев:
- **Бэкенд (Laravel):** `C:\projects\padel` — репо `goldkazyna/padel`, прод `padel-p.kz`
- **Фронтенд (Flutter):** `C:\projects\padel_app` — репо `goldkazyna/padell_app`

Каждая фича — отдельный файл. Внутри: спецификация, какие файлы трогали
(с путями), ключевые потоки, список коммитов, инструкции по деплою и тесту,
известные нюансы/доработки.

## Фичи
- [Round Robin (индивидуальный турнир)](round_robin.md) — новый тип турнира,
  полный стек: создание, проведение (веб + мобила), live, история, рейтинг.
