# Релиз 1.7.2

> Пользовательские изменения для App Store / Google Play.

## Текст для сторов

```
Тренировки и новый формат турниров

• Раздел «Тренировки». Тренеры создают занятия, игроки записываются в один тап. На экране тренировки видно свободные места кружками — занимайте своё. Напоминания придут за сутки, за два часа и за час до начала.

• Новый формат турнира «Эскалера» — лестница из кортов. Наверху сильнейшие, после каждого раунда победители поднимаются, проигравшие опускаются. Формат играется целиком в приложении: создание, ввод счёта, таблица и live-экран для участников.

• Таблица турнира картинкой стала аккуратнее: аватары и отметки верификации, компактные колонки, одинаковый вид на любом телефоне — размер больше не зависит от системного шрифта.

• Разбор выступления от ИИ теперь работает во всех форматах турниров и объясняет, за что начислен рейтинг в каждом матче.

• Организаторам: число кортов задаётся вручную при создании турнира, призы можно включить и после создания, отменённые турниры удаляются из списка.

Исправили порядок клубов в бронировании и мелкие огрехи вёрстки.
```

## Что вошло

### Новое
- **Раздел «Тренировки»**: кабинет тренера (создание занятия, список записавшихся с телефонами, звонок и WhatsApp, завершение и отмена), экраны игрока (список ближайших, запись, «Мои тренировки» в профиле), плитка на главной с бейджем, напоминания за сутки / 2 часа / час, уведомления тренеру о записи и отписке.
- **Формат «Эскалера»**: создание и проведение из приложения, ввод счёта, генерация раундов, завершение; live-экран для игрока с ярусами кортов; место в истории турниров и в профиле; описание формата в разделе «О турнирах».

### Улучшения
- Выгрузка таблицы картинкой: аватары и отметки верификации во всех форматах, ширина колонок по содержимому, независимость от системного размера шрифта, меньший вес файла.
- ИИ-разбор выступления работает во всех девяти форматах и считает изменение рейтинга по каждому матчу.
- Число кортов задаётся вручную при создании турнира (кроме Americano Flex) и пересчитывается при смене числа участников.
- Призовой турнир и текст призов правятся при редактировании.
- Отменённые турниры можно удалить из карточки списка.
- Порядок клубов в бронировании стал предсказуемым; в супер-админке появилась ручная сортировка.

### Исправления
- Счёт мячей в выгрузке больше не переносится на две строки.
- Бейдж тренировок обновляется после отмены занятия, при отсутствии занятий показывает NEW.
- Мелкие правки вёрстки: единый стиль кнопок, монохромные иконки, цены с разделителем тысяч.
