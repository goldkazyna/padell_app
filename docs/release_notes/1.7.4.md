# Релиз 1.7.4

> Накопительный файл. Пополняется по мере правок, текст для сторов дописывается перед выпуском.

## Что вошло

### Новое
- **Отказ от ответственности (waiver)**: экран подписи с переходом по QR — игрок подписывает документ клуба прямо в приложении. `коммиты 105d014, 7dbfd3f, b34046f`.
- **Запись парой в мобильной админке**: организатор заводит пару целиком, не по одному игроку. `коммит 6e0ed77`.
- **Настройки Мексикано в редактировании турнира**: количество раундов (пока турнир не начался), плей-офф, тип сетки (топ-4 в финал или топ-8 через полуфиналы) и формат пар в полуфиналах. Раньше у Мексикано в настройках не было ничего своего — менять что-либо приходилось из веб-панели.
- **Тип плей-офф и формат пар при создании Мексикано**: раньше была только галочка «с плей-офф», а какой именно — выбрать было нельзя.
- **Клуб-площадка в настройках турнира**: поле «Клуб (площадка)» появилось в редактировании турнира — раньше площадку можно было выбрать только при создании, а поменять или убрать уже никак. Поиск по названию, адресу или городу, крестик убирает площадку.

### Улучшения
- Названия кортов в карточке турнира больше не съезжают: сервер отдаёт их позиционно, и корт без своего названия подписывается «Корт N», а не забирает имя соседнего.

### Исправления
- Плей-офф у Мексикано, созданного в приложении, не строился: тип сетки не задавался, и на составе меньше восьми игроков сетка не создавалась вообще, без единого сообщения. Теперь тип выбирается при создании, а турниры из старых сборок сервер считает сеткой «только финал».
- Сообщение о необходимости входа при подписании waiver заменено на понятное, с кнопкой входа. `коммит b34046f`.
- Вертикальные штрихи подписи больше не теряются. `коммит 7dbfd3f`.

## Что нужно на сервере

Ничего дополнительно включать не нужно: поле `venue_club` в ответе админского API турнира уже выкачено вместе с бэкендом.
