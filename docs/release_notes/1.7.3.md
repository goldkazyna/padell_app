# Релиз 1.7.3

> Пользовательские изменения для App Store / Google Play.

## Текст для сторов

```
Достижения и турниры на три группы

• Достижения. Пятнадцать медалей за реальные результаты: первая победа, серия из пяти побед подряд, турнир без единого поражения, все десять форматов, 50 турниров. Медаль отчеканена из бронзы, серебра или золота — металл зависит от того, насколько трудно её взять. Незакрытая показывает, сколько осталось до цели. Тап открывает разбор: за что дают, ваш результат и сколько процентов игроков её уже получили. Чужие медали видно на карточке игрока.

• Турниры Американо на три группы. Появилась общая таблица всех групп — по ней и строится плей-офф: первые четыре места ждут соперников в полуфинале, места с пятого по двенадцатое играют четвертьфинал. У каждого места видно, куда оно ведёт.

• Описание турнира больше не обрезается наглухо: пять строк и ссылка «показать всё». Текст выделяется пальцем — номер для предоплаты наконец можно скопировать.

• Организаторам: приглашение теперь редактируется перед отправкой — заголовок, текст и превью «как увидит игрок». Ограничение в десять приглашений снято.

• Формат «Эскалера» теперь называется Ladder.

Исправили турниры на три и четыре группы, которые при редактировании из приложения превращались в одногрупповые.
```

## Что вошло

### Новое
- **Достижения**: пятнадцать медалей в пяти группах (первые шаги, победы, рейтинг, кругозор, вместе). Считаются из истории матчей, турниров и рейтинга — ничего дополнительно собирать не нужно. Блок в своём профиле, отдельный экран со всеми, лист по тапу с условием и долей игроков, полученные медали на карточке другого игрока. Уведомление о новой медали приходит одно на пачку.
- **Общая таблица Американо** при трёх группах и больше — в экране турнира для игрока и в админском экране. Метка ПФ/ЧФ у места, буква группы рядом с именем.
- **Четвертьфинал в плей-офф Американо** на трёх группах: топ-4 ждут в полуфинале, места 5–12 играют четвертьфинал.
- **Выбор «кто собирает пары»** при создании парного Just Padel It: сами игроки или админ.

### Улучшения
- Описание турнира: пять строк вместо трёх, выделение текста пальцем, ссылка «показать всё» появляется и на телефонах с крупным системным шрифтом.
- Текст приглашения на турнир правится перед отправкой: заголовок, текст, превью и возврат к заготовке.
- Лимит в десять приглашений на турнир снят.
- Формат «Эскалера» переименован в Ladder.

### Исправления
- Турнир на три или четыре группы больше не схлопывается в одну при сохранении настроек из приложения.
- «Создать пары» не предлагается, когда пары собрали сами игроки при записи, — турнир стартует сразу.
- При сборе пар админом открывается экран Just Padel It, а не экран группового турнира.
- Экран достижений приведён к общему виду приложения: кнопка «назад», заголовок и нижнее меню как на остальных экранах.

## Что включить на сервере

Достижения работают сразу, но уведомления о новых медалях по умолчанию выключены. Включить вместе с выходом релиза:

```
ACHIEVEMENTS_PUSH_ENABLED=true   # в .env
php artisan config:clear
```

Без сброса кэша конфига значение не подхватится.
